# Geist and Geist Mono

`Geist-Variable.woff2` and `GeistMono-Variable.woff2` are the Geist typefaces,
Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font),
licensed under the SIL Open Font License, Version 1.1:
https://openfontlicense.org/open-font-license-official-text/

They are the latin-subset variable builds that ship inside the `next` package
(`next/dist/next-devtools/server/font/`), copied here so the web build does not
fetch from Google Fonts. The OFL requires the license text to travel with the
fonts: place the official `OFL.txt` from the Geist repository next to this file.
