# Contributing to SemanticOS

Thank you for your interest in contributing to SemanticOS! 

## Development Environment
1. Ensure you have Python 3.12+, Node 20+, Docker, and UV installed.
2. The project has an API layer (`uvicorn`) and a UI layer (`Next.js`).

## Branching & Pull Requests
- Use standard branch names (`feat/xyz`, `fix/abc`).
- Write clear commit messages and PR descriptions.
- Ensure all CI tests pass before requesting a review.

## Code Style
- We use standard Python formatting (`ruff`).
- For the frontend, we use Prettier and ESLint.

## Reporting Issues
Please use the GitHub Issue Tracker to report bugs or request features. Include log snippets and your deployment architecture if reporting a bug.
